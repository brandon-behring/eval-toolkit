# `docs/archive/`

Historical audit / planning artifacts retained for citation context.
Not navigated by the live mkdocs site (intentionally absent from
`mkdocs.yml`); intended for reading via the GitHub repo browser when
tracing the provenance of older release decisions.

If a document here becomes load-bearing again (e.g., a section is
cited by current docs), move it back into `docs/` and add a nav
entry rather than linking into `docs/archive/`.
